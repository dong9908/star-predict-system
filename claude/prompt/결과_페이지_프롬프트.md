# 별자리 찾기 결과 페이지 (Constellation Find Result Page) 구현 프롬프트

## 📋 페이지 개요
사용자가 업로드한 별자리 사진을 AI가 분석하여 결과를 표시하는 페이지를 구현한다.
- 경로: `/constellation-find-result`
- ConstellationFindPage에서 "분석하기" 버튼을 클릭하면 이동
- 분석 결과로 가장 일치율이 높은 별자리를 상세 정보와 함께 표시

## 🎨 레이아웃 구조

### 1. 왼쪽 섹션 (55%)
- **업로드된 사진 + 시각화 패널** (상단)
  - 사용자가 업로드한 별자리 사진 표시
  - 사진 위에 인식된 별자리의 별 배치를 오버레이로 표시 (SVG)
  - 줌/이동 컨트롤 (-/+/초기화 버튼)
  
- **분석된 별자리 정보 섹션** (하단)
  - 일치율 과 함께 별자리 순위 표시 (예: "1위 (일치도 92%)")
  - 별자리의 한글명과 영문명
  - 짧은 소개 텍스트
  - **주요 별들** 부분
    - 인식된 별자리의 주요 별들을 버튼/칩 형태로 표시
    - 각 별의 이름 (한글/영문)
  - **별자리 이야기** 섹션
    - 해당 별자리의 신화 또는 역사적 배경

### 2. 오른쪽 섹션 (45%)
- **분석 결과 헤더**
  - "분석 결과" 제목
  - "공유하기" 버튼 (SNS 공유)
  - "새로 분석하기" 버튼 (ConstellationFindPage로 이동)
  
- **별자리 매칭 결과 리스트**
  - 분석된 상위 5개의 별자리 매칭 결과 표시
  - 각 항목 구성:
    - 순위 (1~5)
    - 별자리 한글명
    - 일치도 퍼센트 (%)
    - 선택한 별자리는 보라색 테두리로 강조 표시
  - 클릭 시 왼쪽 섹션의 정보 업데이트 (다른 별자리 선택 가능)
  - 스크롤 가능한 리스트 형태

## 🔧 구현 기능 요구사항

### 필수 기능
1. **데이터 전달**
   - ConstellationFindPage에서 선택된 이미지 파일을 ConstellationFindResultPage로 전달
   - React Router의 `useLocation()` 또는 `useNavigate()` state 활용

2. **이미지 표시**
   - 업로드된 사진을 canvas 또는 img 태그로 표시
   - 사진 위에 별 배치 오버레이 가능

3. **AI 분석 시뮬레이션**
   - 실제 AI 분석 대신 mock 데이터 사용
   - 각 별자리마다 일치도(%) 데이터 포함
   - 예: [{name: '오리온자리', engName: 'Orion', percentage: 92}, ...]

4. **별자리 선택 및 상세 정보 표시**
   - 매칭 결과 리스트에서 별자리 클릭 시 선택 상태 변경
   - 왼쪽 섹션의 정보 동적 업데이트
   - 기본으로 가장 높은 일치도를 가진 별자리가 선택됨

5. **공유 기능**
   - "공유하기" 버튼 클릭 시 분석 결과를 공유하는 팝업 또는 모달 표시
   - Twitter, Facebook, KakaoTalk, Link Copy 등의 옵션

6. **새로 분석하기 버튼**
   - 클릭 시 ConstellationFindPage로 이동
   - 이전에 업로드한 사진 정보는 초기화

7. **반응형 디자인**
   - 데스크톱: 좌우 2열 레이아웃
   - 태블릿/모바일: 스택 레이아웃으로 변경

### 선택 기능 (확장 가능)
- 분석 결과를 이미지로 저장
- 분석 결과를 마이페이지에 저장/히스토리 관리
- 더 자세한 분석 정보 (별 좌표, 크기 정보 등)
- 다른 사용자의 분석 결과와 비교

## 🎯 디자인 참고
- 기존 ASTRA 앱의 다크테마 유지 (배경: 어두운 파랑/검정, 강조색: 보라색)
- 이미지 프레임: 어두운 배경으로 사진이 돋보이도록
- 결과 카드: 선택된 항목은 보라색 테두리 + 배경색 강조
- 일치도 표시: 퍼센트 텍스트 또는 프로그레스 바
- 폰트: 한글(Pretendard/Noto Sans KR), 영문(Inter/Poppins)
- 이미지: front-img 폴더 안에 있는 별자리 찾기 - 결과 요소-1.png 사용

## 🔗 필수 수정 사항

### 1. ConstellationFindPage.jsx
- "분석하기" 버튼 추가
  - 업로드된 파일이 있을 때만 활성화
  - 클릭 시 `/constellation-find-result`로 네비게이트하면서 이미지 state 전달
  - 예: `navigate('/constellation-find-result', { state: { image: uploadedFile } })`

### 2. App.jsx
- 새로운 라우트 추가:
  ```javascript
  <Route path="/constellation-find-result" element={<ConstellationFindResultPage />} />
  ```
