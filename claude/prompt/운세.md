# 운세 상세 결과 페이지 구현 프롬프트

## 요구사항

FortuneReadingPage에서 "💳 ₩1,900 결제하고 운세 전체 보기" 버튼을 클릭하면, 오늘의 종합 운세 컨텐츠를 상세한 정보를 제공하도록 구현한다.

## 페이지 레이아웃 및 구조

### 1. 페이지 헤더
- **제목**: "✦ 오늘의 운세 상세 결과"
- **부제**: "전문 점술가와 함께하는 오늘의 메시지"

### 2. 사용자 정보 섹션
- **프로필 영역**:
  - 별자리 아이콘/심볼
  - 사용자명
  - 생년월일 (예: 2000.04.12)
  - 성별 (예: 남성)
  - 오른쪽에 별자리 기운 점수 (예: "행운지수 88")

### 3. 날짜 정보
- 현재 날짜 및 요일 (예: "2026년 8월 25일 월요일")

### 4. 종합 운세 섹션
- **섹션 제목**: "✦ 오늘의 종합 운세"
- **내용**: 오늘의 전반적인 운세 메시지
- **상세 텍스트**: 2-3문단의 상세한 운세 해석

### 5. 카테고리별 운세 섹션
운세를 다음 카테고리로 구분하여 표시:

#### 5.1 사랑운
- **아이콘**: 💘 또는 하트
- **제목**: "사랑운"
- **운세 점수**: ★★★★☆ (1-5개 별)
- **상세 내용**: 사랑 관련 메시지 (2-3문장)
- **배경색**: 핑크/로즈 톤

#### 5.2 재물운
- **아이콘**: 💰 또는 동전
- **제목**: "재물운"
- **운세 점수**: ★★★★☆
- **상세 내용**: 재물 관련 메시지
- **배경색**: 황금/노란 톤

#### 5.3 건강운
- **아이콘**: 🏥 또는 하트
- **제목**: "건강운"
- **운세 점수**: ★★★★☆
- **상세 내용**: 건강 관련 메시지
- **배경색**: 초록/민트 톤

#### 5.4 직업운
- **아이콘**: 💼 또는 직업 심볼
- **제목**: "직업운"
- **운세 점수**: ★★★☆☆
- **상세 내용**: 직업/커리어 관련 메시지
- **배경색**: 파란/인디고 톤

#### 5.5 인간관계운
- **아이콘**: 👥 또는 사람
- **제목**: "인간관계운"
- **운세 점수**: ★★★★★
- **상세 내용**: 인간관계 관련 메시지
- **배경색**: 보라/라벤더 톤

### 6. 종합 조언 섹션
- **제목**: "✦ 오늘의 조언"
- **내용**: 전체적인 조언 메시지 (3-4문장)
- **팁**: "오늘을 더 행운으로 만드는 팁" 등의 추가 정보

### 7. 운세 갱신 정보
- **마지막 갱신**: "오늘의 운세는 자정에 갱신됩니다"
- **공지사항**: 운세에 대한 안내 문구

## 디자인 및 스타일

### 색상 팔레트
- **배경**: 다크 네이비 (#0f172a)
- **텍스트 기본**: 흰색 (#ffffff)
- **텍스트 보조**: 라이트 그레이 (#cbd5e1)
- **강조 색상**: 보라색 (#9333ea)
- **카테고리별 색상**:
  - 사랑운: #ec4899 (핑크)
  - 재물운: #f59e0b (황금)
  - 건강운: #10b981 (초록)
  - 직업운: #3b82f6 (파란)
  - 인간관계: #a855f7 (보라)

### 카드 디자인
- 각 카테고리는 카드 형태로 표시
- 카드마다 왼쪽 테두리에 해당 카테고리 색상 (2-3px)
- 카드 배경: 반투명 검은색 (rgba)
- 호버 효과: 약간의 그림자 추가 및 스케일 변화
- 모서리 반경: 0.75rem

### 레이아웃
- **그리드**: 전체 너비 기반 1열 또는 2열 레이아웃
- **반응형**: 모바일(1열), 태블릿(1-2열), 데스크톱(2열)
- **간격**: 1.5rem ~ 2rem 마진

## 기능 요구사항

### 1. 결제 상태 확인
- 결제 여부를 확인하여 상세 내용 표시/숨김
- 미결제 상태: 프리미엄 박스만 표시
- 결제 상태: 전체 상세 내용 표시

### 2. 모달/페이지 전환
- **옵션 A**: 모달로 표시 (FortuneReadingPage 내에서)
- **옵션 B**: 새로운 페이지로 이동 (/fortune-result 라우트)
- 추천: 옵션 B (새 페이지)

### 3. 동적 데이터
- localStorage의 user 정보 활용
- 현재 날짜/시간 동적 표시
- 별자리별 운세 텍스트 다르게 표시

### 4. 운세 점수
- 각 카테고리별로 1-5개 별 점수 표시
- 점수는 별자리에 따라 다르게 계산
- 애니메이션 효과 추가 가능

### 5. 인쇄/공유 기능
- 운세 결과 인쇄 버튼 (선택사항)
- SNS 공유 버튼 (선택사항)

### 6. 닫기/돌아가기
- 모달: X 버튼으로 닫기
- 페이지: 뒤로가기 버튼
- 헤더 네비게이션에서도 접근 가능
