# 별자리 웹사이트 개선 작업계획

## 개요
프론트엔드 코드만을 수정하여 사용자 경험을 개선하는 프로젝트입니다.

---

## 1. 별자리 위치 찾기 (검색 기능 개선)

### 목표
- 기존 별자리 정보를 초기에 모두 표시
- 실시간 검색 기능 구현 (입력 시 일치하는 별자리만 필터링)
- 후추: 향후 서버 DB와 연동 가능하도록 구조화

### 작업 내용
1. 검색 입력 필드 추가
2. 입력값에 따른 필터링 로직 구현
3. 검색 결과 실시간 업데이트
4. UI/UX 개선 (입력 필드 스타일, 결과 표시)

### 예상 파일
- `src/components/ConstellationSearch.jsx` (또는 해당 위치)

---

## 2. 헤더 개선 (모바일 메뉴)

### 목표
- 모바일 햄버거 토글 메뉴 구현
- 현재 선택된 페이지를 다른 색깔로 표시

### 작업 내용
1. 현재 페이지 경로 감지 로직 구현
2. 활성화된 메뉴 항목에 특정 스타일 적용
3. 반응형 CSS 수정 (@media mobile)
4. 메뉴 활성화 상태 시각화 (색상, 밑줄, 배경색 등)

### 예상 파일
- `src/components/Header.jsx` (또는 Navigation 컴포넌트)
- `src/styles/header.css` (또는 모바일 스타일)

---

## 3. 메인 페이지 개선 (모바일 반응형)

### 목표
- 모바일 화면에서 제목과 부제목이 너무 작아지는 현상 개선

### 작업 내용
1. 반응형 폰트 크기 설정 (rem, em, vw 등 사용)
2. 모바일 뷰포트에 최적화된 제목 크기 계산
3. CSS 미디어 쿼리 수정
4. 텍스트 레이아웃 최적화

### 예상 파일
- `src/components/MainPage.jsx`
- `src/styles/main.css` 또는 해당 스타일 파일

---

## 4. 별자리 정보 페이지 개선

### 목표
- 불필요한 관측 정보 영역 삭제

### 작업 내용
1. 불필요한 관측 정보 UI 요소 제거
2. 레이아웃 재정렬 (공간 활용 최적화)
3. 남은 정보의 가독성 개선

### 예상 파일
- `src/components/ConstellationDetail.jsx` (또는 유사 컴포넌트)
- 해당 스타일 파일

---

## 5. 별자리 도감 (카탈로그) 개선

### 목표
- 영역별 스크롤 구현 (카드 영역만 독립적으로 스크롤)

### 작업 내용
1. 레이아웃 구조 재설계 (헤더는 고정, 카드 영역만 스크롤)
2. CSS `overflow: auto` 또는 자식 요소별 스크롤 설정
3. 스크롤 성능 최적화

### 기술 스택
- CSS: `overflow`, `max-height`, `display: flex` 등
- React: 필요시 가상 스크롤 라이브러리 고려 (react-window 등)

### 예상 파일
- `src/components/ConstellationCatalog.jsx`
- `src/styles/catalog.css`

---

## 6. 마이 페이지 개선

### 목표
- 프로필 정보 시인성 개선
- 방안: "이름 / 획득한 별자리 / 칭호" 한 줄 표시 또는 크기 확대

### 작업 내용

#### Option A: 한 줄 표시
1. 프로필 정보를 가로 배열로 재구성
2. 구분자(/) 추가
3. 반응형 디자인 (모바일에서 여러 줄로 표시 가능)

#### Option B: 크기 확대
1. 획득한 별자리 아이콘 크기 증대
2. 칭호 텍스트 폰트 사이즈 증대
3. 레이아웃 재조정

### 예상 파일
- `src/components/MyPage.jsx` 또는 `ProfileSection.jsx`
- 해당 스타일 파일

## 개발 순서 (우선순위)

1. **헤더 개선** (메뉴 네비게이션 필수)
2. **메인 페이지 개선** (사용자 진입점)
3. **별자리 위치 찾기** (검색 기능)
4. **별자리 도감** (레이아웃 개선)
5. **별자리 정보 페이지** (정리 작업)
6. **마이 페이지** (마무리)

---

## 기술 고려사항

- **반응형 디자인**: 모바일/태블릿/데스크톱 모두 고려
- **접근성**: 색상만으로 상태 구분하지 않기
- **성능**: 불필요한 리렌더링 최소화
- **일관성**: 전체 사이트의 디자인 일관성 유지
