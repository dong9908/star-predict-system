프론트 폴더에 있는 코드만을 수정해서 더 나은 웹 사이트를 만들꺼야

이 구성을 참고해서 웹 사이트를 보수하는 만드는 작업계획을 작성해줘
작업계획은 front-img 폴더 안에 수정.md 파일로 저장해줘

세부사항
- 별자리 위치 찾기: 별자리 검색에서 현재 등록되어 있는 별자리 정보가 보이도록 하고, 글자를 입력하면 일치하는 별자리를 보여주도록 구현해주세요 (나중에 서버 DB랑 연동).
- 헤더: (모바일) 햄버거 토글 메뉴에서 자신이 선택한 페이지만 다른 색깔로 표시되도록 구성해주세요.
- 메인: (모바일) 모바일 메인 화면일 때 제목과 부제목이 너무 작아지는 현상을 개선해주세요.
- 별자리 정보: 불필요한 관측 정보 영역을 삭제해주세요.
- 별자리 도감: 카드 있는 부분만 따로 스크롤되도록 영역별 스크롤을 적용해주세요.
- 마이 페이지: 프로필 부분의 정보를 '이름 / 획득한 별자리 / 칭호'로 한 줄로 수정하거나, 획득한 별자리와 칭호의 크기를 키워 시인성을 높여주세요.
