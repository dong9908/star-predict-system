# 별자리 정보 페이지 (Constellation Information Page) 구현 프롬프트

## 📋 페이지 개요
사용자가 별자리에 대한 상세한 정보를 조회하고 검색할 수 있는 페이지를 구현한다.
- 경로: `/constellation-info`
- Header의 "별자리 정보" 버튼에서 이동

## 🎨 레이아웃 구조

### 1. 왼쪽 섹션 (60%)
- **별자리 시각화 패널** (상단)
  - 선택된 별자리의 별 배치를 시각적으로 표현 (SVG 또는 Canvas)
  - 별들을 선으로 연결하여 별자리 형태 표시
  - 줌/이동 컨트롤 (-/+/전체보기 버튼)
  
- **별자리 상세 정보 섹션** (하단)
  - 선택된 별자리의 한글명과 영문명
  - 소개 텍스트 (별자리 설명)
  - **주요 별들** 부분
    - 별자리에 속한 주요 별들을 버튼/칩 형태로 표시
    - 각 별의 이름 (한글/영문)
  - **관측 정보** 섹션
    - 현재 시간 (시:분 형식)
    - 관측 고도 (도)
    - 방향 (방위각, 한글 표시: 북, 남동쪽 등)
  - **별자리 이야기** 섹션
    - 해당 별자리의 신화 또는 역사적 배경을 텍스트로 표시
    - 여러 단락의 긴 텍스트 지원

### 2. 오른쪽 섹션 (40%)
- **검색 바** (상단)
  - 별자리를 검색할 수 있는 입력 필드
  - 실시간 검색 필터링 지원
  
- **별자리 목록 패널**
  - 스크롤 가능한 리스트
  - 각 항목은 카드 형태
    - 별자리 아이콘/이미지
    - 별자리 한글명
    - 별자리 영문명
  - 현재 선택된 별자리는 하이라이트 (보라색 테두리)
  - 클릭 시 해당 별자리 정보 왼쪽 섹션에 표시

## 🔧 구현 기능 요구사항

### 필수 기능
1. **별자리 목록 데이터**
   - 최소 10개 이상의 별자리 정보 포함 (이름, 영문명, 주요 별들, 설명, 이야기)
   - 관측 좌표 정보 (고도, 방위각)

2. **검색 기능**
   - 한글명 또는 영문명으로 검색 가능
   - 실시간 필터링

3. **별자리 선택**
   - 목록에서 별자리 클릭 시 선택 상태 변경
   - 왼쪽 섹션 정보 동적 업데이트

4. **시각화**
   - 선택된 별자리의 별 배치 그래픽 표시
   - 가능하면 Star Chart API 또용하거나 SVG로 구현

5. **반응형 디자인**
   - 데스크톱: 좌우 2열 레이아웃
   - 태블릿/모바일: 스택 레이아웃으로 변경

### 선택 기능 (확장 가능)
- 위치 기반 관측 정보 (사용자 위도/경도 입력)
- 실시간 별자리 가시 시간대 계산
- 별자리 사진 갤러리
- 관련 별자리 추천

## 🎯 디자인 참고
- 기존 ASTRA 앱의 다크테마 유지 (배경: 어두운 파랑/검정, 강조색: 보라색)
- 별자리 아이콘: 간단한 라인 아트 스타일
- 카드/패널: 반투명 배경 + 테두리 (보라색 강조색)
- 폰트: 한글(Pretendard/Noto Sans KR), 영문(Inter/Poppins)
