## 페이지 구조 및 네비게이션 매핑

### 1. Hero Section 버튼

#### 1.1 "사진으로 별자리 찾기" (보라색 버튼)
- **현재**: `navigate('/')`로 메인 페이지에 머무름
- **변경**: `navigate('/constellation-find')`로 이동
- **대상 페이지**: ConstellationFindPage
- **설명**: 사진을 업로드하여 별자리를 찾는 페이지

#### 1.2 "내 위치에서 찾아보기" (어두운 버튼)
- **현재**: `navigate('/')`로 메인 페이지에 머무름
- **변경**: `navigate('/constellation-location')`으로 이동
- **대상 페이지**: ConstellationLocationPage
- **설명**: GPS 위치와 시간을 기반으로 별자리를 찾는 페이지

### 2. Feature Cards (하단 카드 3개)

#### 2.1 카드 01: "사진으로 별자리 찾기"
- **현재**: `navigate('/')`로 메인 페이지에 머무름

#### 2.2 카드 02: "내 위치에서 별자리 찾기"
- **현재**: `navigate('/')`로 메인 페이지에 머무름
- **변경**: `navigate('/constellation-location')`으로 이동
- **클릭 영역**: 전체 카드 또는 링크 텍스트
- **대상 페이지**: ConstellationLocationPage

#### 2.3 카드 03: "별자리 정보"

## 구현 사항

### 1. MainPage.jsx 수정

#### 1.1 Hero Section 버튼 수정
```javascript
// PrimaryButton - "사진으로 별자리 찾기"
<PrimaryButton onClick={() => navigate('/constellation-find')}>
  사진으로 별자리 찾기
  <ButtonIcon>
    <ArrowRight size={16} />
  </ButtonIcon>
</PrimaryButton>

// SecondaryButton - "내 위치에서 찾아보기"
<SecondaryButton onClick={() => navigate('/constellation-location')}>
  내 위치에서 찾아보기
</SecondaryButton>
```

#### 1.2 Feature Cards 수정
각 FeatureCard 컴포넌트에 `onLinkClick` prop 추가:
```javascript
{features.map((feature) => (
  <FeatureCard
    key={feature.number}
    number={feature.number}
    title={feature.title}
    description={feature.description}
    linkText={feature.linkText}
    onLinkClick={() => {
      if (feature.number === '01') {
        navigate('/constellation-find')
      } else if (feature.number === '02') {
        navigate('/constellation-location')
      } else if (feature.number === '03') {
        navigate('/constellation-info')
      }
    }}
  />
))}
```

#### 1.3 ConstellationViewer 수정 (선택사항)
```javascript
// 클릭 가능한 별자리 요소에 이벤트 핸들러 추가
const handleConstellationClick = () => {
  navigate('/constellation-location')
}
```

### 2. FeatureCard.jsx 수정

FeatureCard 컴포넌트를 수정하여 `onLinkClick` prop을 받아 클릭 이벤트 처리:
```javascript
function FeatureCard({ number, title, description, linkText, onLinkClick }) {
  return (
    <Card onClick={onLinkClick} style={{ cursor: 'pointer' }}>
      {/* ... 기존 내용 ... */}
      <LinkText onClick={onLinkClick}>
        {linkText} →
      </LinkText>
    </Card>
  )
}
```

### 3. ConstellationViewer.jsx 수정 (선택사항)

별자리 시각화 클릭 시 위치 찾기 페이지로 이동하는 기능 추가
