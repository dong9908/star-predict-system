# 회원 정보 수정 페이지 구현 프롬프트

## 요구사항

마이 페이지(MyPage)에서 "회원 정보 수정" 버튼을 클릭하면, 회원 정보를 수정할 수 있는 페이지로 이동합니다.
회원 정보 수정.png 이미지를 참고하여 동일한 레이아웃과 디자인으로 구현합니다.

## 페이지 레이아웃 및 구조

### 1. 페이지 헤더
- **제목**: "회원 정보 수정"
- **부제**: 선택사항 (없어도 됨)
- **뒤로가기 버튼**: 마이 페이지로 돌아가기

### 2. 회원 정보 입력 폼

#### 2.1 이름 필드
- **라벨**: "이름"
- **입력 필드**: 텍스트 입력
- **타입**: text
- **플레이스홀더**: "이름을 입력하세요"
- **필수**: ✅ 필수 입력 필드

#### 2.2 생년월일 필드
- **라벨**: "생년월일"
- **입력 필드**: 날짜 입력
- **타입**: date 또는 text (YYYY.MM.DD 형식)
- **플레이스홀더**: "2000.04.12"
- **필수**: ✅ 필수 입력 필드

#### 2.3 이메일 필드
- **라벨**: "이메일"
- **입력 구조**: 두 개의 입력 필드 (@ 기호로 분리)
  - 첫 번째 필드: 이메일 앞부분 (예: user)
  - @ 기호: 고정 텍스트
  - 두 번째 필드: 도메인 (예: gmail.com)
- **타입**: text
- **플레이스홀더**: "user" @ "example.com"
- **필수**: ✅ 필수 입력 필드

#### 2.4 비밀번호 필드
- **라벨**: "비밀번호"
- **입력 필드**: 텍스트 입력 (마스킹)
- **타입**: password
- **플레이스홀더**: "새 비밀번호를 입력하세요"
- **필수**: ❌ 선택 입력 (수정할 때만 입력)
- **요구사항**: 
  - 최소 8자 이상
  - 영문, 숫자, 특수문자 조합 권장

#### 2.5 비밀번호 확인 필드
- **라벨**: "비밀번호 확인"
- **입력 필드**: 텍스트 입력 (마스킹)
- **타입**: password
- **플레이스홀더**: "비밀번호를 다시 입력하세요"
- **필수**: ❌ 선택 입력 (비밀번호 입력 시에만)
- **유효성 검사**: 비밀번호와 일치해야 함

#### 2.6 휴대폰 번호 필드
- **라벨**: "휴대폰"
- **입력 필드**: 텍스트 입력
- **타입**: tel 또는 text
- **플레이스홀더**: "010-1234-5678"
- **형식**: 자동 포맷팅 (010-0000-0000)
- **필수**: ✅ 필수 입력 필드

### 3. 하단 버튼

#### 3.1 저장하기 버튼
- **텍스트**: "저장하기"
- **색상**: 보라색 (#9333ea)
- **호버 효과**: 밝은 보라색 (#a855f7)
- **동작**: 
  - 입력 데이터 유효성 검사
  - API 호출로 서버에 저장
  - 성공 시 마이 페이지로 이동
  - 실패 시 에러 메시지 표시

## 디자인 및 스타일

### 색상 팔레트
- **배경**: 다크 네이비 (#0f172a)
- **카드 배경**: rgba(30, 41, 59, 0.6)
- **테두리**: rgba(147, 51, 234, 0.3)
- **텍스트**: 흰색 (#ffffff)
- **보조 텍스트**: 라이트 그레이 (#cbd5e1)
- **입력 필드**: rgba(15, 23, 42, 0.8) 배경, 보라색 테두리
- **버튼**: 보라색 (#9333ea)

### 레이아웃
- **최대 너비**: 600px (폼 기준)
- **중앙 정렬**: 화면 중앙에 배치
- **여백**: 상하 2rem, 좌우 1rem
- **입력 필드 간격**: 1.5rem
- **모바일 반응형**: 좌우 패딩 증가

### 폼 스타일
- **카드 방식**: 보라색 테두리가 있는 카드
- **모서리 반경**: 0.75rem
- **입력 필드**:
  - 배경: 어두운 배경
  - 테두리: 얇은 보라색 테두리
  - 패딩: 0.75rem 1rem
  - 폰트 크기: 0.875rem

## 기능 요구사항

### 1. 데이터 로드
- 페이지 진입 시 localStorage에서 현재 사용자 정보 로드
- 기존 정보를 입력 필드에 표시

### 2. 입력 유효성 검사
- **이름**: 2자 이상, 50자 이하
- **생년월일**: 유효한 날짜 형식, 미래 날짜 불가
- **이메일**: 유효한 이메일 형식
- **비밀번호**: 입력했을 경우만 검사 (8자 이상)
- **비밀번호 확인**: 비밀번호와 일치 확인
- **휴대폰**: 유효한 번호 형식 (10-11자리)

### 3. 폼 제출
- "저장하기" 버튼 클릭 시 유효성 검사
- 검사 통과 시 API 호출
- API 응답 처리:
  - 성공: 성공 메시지 표시 후 마이 페이지로 이동
  - 실패: 에러 메시지 표시

### 4. 오류 처리
- **필드 오류**: 각 필드 아래에 에러 메시지 표시
- **일반 오류**: 상단에 알림 메시지 표시
- **네트워크 오류**: 재시도 옵션 제공

### 5. 로그인 상태 확인
- 로그인하지 않은 경우 로그인 페이지로 리다이렉트

### 6. 네비게이션
- 뒤로가기 버튼: 마이 페이지로 이동
- 저장 성공: 자동으로 마이 페이지로 이동

## API 연동

### 회원 정보 조회 (GET)
- **엔드포인트**: `/api/users/profile`
- **응답**: 현재 사용자 정보

### 회원 정보 수정 (PUT/PATCH)
- **엔드포인트**: `/api/users/profile`
- **요청 데이터**: 수정할 사용자 정보
- **응답**: 수정된 사용자 정보

## 추가 개선 사항 (선택)

1. **실시간 유효성 검사**: 입력하면서 즉시 유효성 검사
2. **필드 변경 감지**: 수정되지 않은 필드 강조 표시
3. **저장 중 상태**: 저장 중 버튼 비활성화 및 로딩 표시
4. **확인 모달**: 저장 전 변경사항 확인 모달
5. **프로필 사진 변경**: 프로필 사진 업로드 기능
6. **주소 필드**: 주소 입력 필드 추가
7. **성별 선택**: 성별 선택 드롭다운 추가
8. **자동 저장**: 주기적인 임시 저장 기능
