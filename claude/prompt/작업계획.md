# 🌟 ASTRA 프로젝트 - React 전환 작업계획

## 📋 프로젝트 개요

- **프로젝트명**: ASTRA (별자리 분석 & 관측 서비스)
- **전환 대상**: HTML/CSS/JavaScript → React (Vite) + Styled-Components
- **현재 상태**: 메인 페이지(index.html) 완성, CSS/JS 보조 파일 완성
- **목표**: 모듈화된 React 컴포넌트 기반 프로젝트로 변환

---

## 📁 프로젝트 구조

```
src/
├── pages/
│   ├── MainPage.jsx          # 메인 페이지 (hero + 기능 카드)
│   ├── LoginPage.jsx         # 로그인 페이지
│   └── SignupPage.jsx        # 회원가입 페이지
├── components/
│   ├── Header.jsx            # 헤더/네비게이션 바 (GNB)
│   ├── Footer.jsx            # 푸터 (아직 미구현, 필요시 추가)
│   ├── ConstellationViewer.jsx # 별자리 뷰어 카드
│   ├── FeatureCard.jsx       # 기능 카드 (3열 그리드)
│   └── styles/
│       ├── Header.styles.js
│       ├── Footer.styles.js
│       ├── ConstellationViewer.styles.js
│       └── FeatureCard.styles.js
├── styles/
│   ├── GlobalStyles.js       # 글로벌 스타일 (reset, 배경 효과)
│   └── theme.js              # 테마 색상 변수
├── App.jsx                   # 라우팅 설정 (React Router)
└── main.jsx                  # 엔트리 포인트
```

## 🎯 작업 단계

### **Phase 1: 프로젝트 초기화 & 기본 설정**

#### Task 1-1: Vite + React 프로젝트 생성
```bash
npm create vite@latest front -- --template react
cd front
npm install
```

#### Task 1-2: 의존성 설치

## 🚀 추가 고려사항

1. **API 연동**: 현재 폼은 `handleAuthSubmit()` Alert만 사용 → 향후 백엔드 API 연동 필요
2. **상태관리**: 복잡도 증가 시 Redux/Zustand 도입 고려
3. **타입 스크립트**: 선택사항 (현재 JavaScript로 진행)
4. **테스트**: Jest + React Testing Library로 단위 테스트 추가 가능
5. **성능**: 코드 스플리팅 (React.lazy)을 통한 번들 최적화
