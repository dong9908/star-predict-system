# 메인 페이지 레이아웃 프롬프트

## 전체 구성

### 1. 히어로 섹션 (Hero Section)
- **레이아웃**: 12칼럼 그리드 (좌측 콘텐츠 7칼럼, 우측 시각화 5칼럼)
- **데스크톱**: 좌우 배치
- **태블릿 이상**: 좌우 배치 유지
- **모바일**: 전체 너비 (100%) 상하 배치로 변경

#### 콘텐츠 (좌측)
```
Badge: "✦ 오늘 밤, 별과 더 가까워지는 방법"
- 배경: rgba(76, 29, 149, 0.6) 반투명 보라색
- 테두리: 1px solid rgba(147, 51, 234, 0.5)
- 텍스트 색상: #d8b4fe
- 패딩: 0.75rem, 반지름: 9999px

Title: "밤하늘을 올려다보는 순간, 별자리가 이야기가 됩니다"
- 데스크톱: font-size 3rem
- 태블릿: font-size 2.25rem
- 모바일: font-size 1.25rem
- 색상: white, line-height: 1.2

Button Group:
- PrimaryButton: "#9333ea" 배경, white 텍스트, hover시 "#a855f7"
  - 텍스트: "사진으로 별자리 찾기"
  - 아이콘: ArrowRight (16px)
  - 모바일에서 전체 너비 (width: 100%)
  - 모바일 높이: 3.5rem
  
- SecondaryButton: "#0f172a" 배경, "#cbd5e1" 텍스트, 테두리 포함
  - 텍스트: "내 위치에서 찾아보기"
  - hover시 배경 "#1e293b"
  - 모바일에서 전체 너비 (width: 100%)
  - 모바일 높이: 3.5rem

#### 시각화 (우측)
- ConstellationViewer 컴포넌트 (별자리 인터랙티브 시각화)
- 데스크톱: 그리드 5칼럼
- 모바일: 전체 너비

**반응형 브레이크포인트**:
- 1024px 이상: 좌우 배치
- 1024px 이하: 상하 배치 (콘텐츠 12칼럼)
- 768px 이하: 모바일 최적화 (버튼 전체 너비, gap 1.5rem)
- 640px 이하: 초소형 모바일 (padding/margin 축소)

### 2. 스카이 이미지 섹션 (Sky Image Section)
```html
<ImageSection>
  <img src="/front-img/이미지.png" alt="Live Sky Seoul" />
</ImageSection>
```

**스타일**:
- 너비: 100%
- 마진: 2rem (상하), 1.5rem (768px 이하), 1rem (640px 이하)
- 테두리: border-radius 0.75rem (0.5rem at 768px, 0px at 640px)
- img: width 100%, height auto, display block, object-fit cover

**용도**: Live Sky Seoul 시각화 (별자리 차트, 위치 정보)

---

### 3. 피쳐 카드 그리드 (Feature Grid) - 2분할 배치
```
01. 사진으로 별자리 찾기
    설명: 밤하늘 사진을 올리면 별자리 이름과 숨겨진 신화 이야기를 알려드려요.
    CTA: 지금 업로드하기

02. 내 위치에서 별자리 찾기
    설명: 현재 위치와 시간 기준으로 별이 있는 정확한 방향과 고도를 확인해요.
    CTA: 하늘 지도 열기
```

**그리드 레이아웃**:
- 데스크톱 (768px 이상): 2칼럼 (grid-template-columns: repeat(2, 1fr))
- 모바일 (768px 이하): 1칼럼 (grid-template-columns: 1fr)

**간격**:
- 데스크톱: gap 1.5rem
- 모바일: gap 1rem
- 초소형 모바일 (640px 이하): gap 0.75rem

**카드 스타일**:
- 배경: rgba(10, 10, 25, 0.8) 반투명 어두운 배경
- 테두리: 1px solid rgba(100, 116, 139, 0.3)
- 테두리-반지름: 1rem
- 패딩: 1.5rem (모바일 1.25rem)

</div>

**여백 관리**:
- 섹션 간 여백: margin-bottom 3rem (Hero), 2rem (768px 이하)
- 최상단 패딩: padding-top 1.5rem (1rem at 768px)

## 반응형 디자인 원칙

1. **데스크톱 (1024px+)**: 히어로는 좌우 2칼럼, 카드는 2칼럼
2. **태블릿 (768px-1023px)**: 히어로는 상하, 카드는 2칼럼 (→ 1칼럼)
3. **모바일 (640px-767px)**: 모든 요소 전체 너비, 버튼 스택
4. **초소형 (640px 이하)**: 폰트 축소, 간격 축소, 터치 친화적 버튼 높이 유지

### 터치 친화성 (모바일)
- 버튼 최소 높이: 3.5rem (touch target 44px 권장)
- 버튼 너비: 100%
- 텍스트 크기: 0.85rem - 1rem (접근성 최소값 16px 유지)
