# ASTRA 반응형 웹사이트 작업 계획

## 📋 프로젝트 개요
- **목표**: CSS 변경만으로 기존 React 컴포넌트를 모바일 중심의 반응형 웹사이트로 전환
- **범위**: front/src 폴더의 *.styles.js 파일만 수정
- **기준 해상도**: 모바일(0-768px), 태블릿(768-1024px), 데스크톱(1024px+)

---

## 🎨 전체 설계 원칙

### 1. 미디어 쿼리 표준화
```
- 모바일: max-width: 768px (기본 레이아웃)
- 태블릿: 768px < width < 1024px (중간 레이아웃)
- 데스크톱: min-width: 1024px (현재 레이아웃)
```

### 2. 글로벌 스타일 수정 대상
- **GlobalStyles.js**: 기본 폰트 크기, 라인 높이, 여백 조정
- **theme.js**: 반응형 스페이싱, 브레이크포인트 정의

### 3. 스타일 작성 패턴
```javascript
// 모바일 우선 접근 (Mobile-First Approach)
const ComponentStyle = styled.div`
  /* 모바일(기본) 스타일 */
  padding: 1rem;
  font-size: 0.875rem;
  
  /* 태블릿 이상 */
  @media (min-width: 768px) {
    padding: 1.5rem;
  }
  
  /* 데스크톱 이상 */
  @media (min-width: 1024px) {
    padding: 2rem;
  }
`
```

### 1. Header (헤더) - 가장 우선순위 높음

#### 모바일 레이아웃 (< 768px)
- **상단 바 높이**: 4rem 유지
- **좌측**: ASTRA 로고만 표시
- **우측**: 햄버거 메뉴 버튼(☰) 추가
- **로그인/회원가입 버튼**: 햄버거 메뉴 내에 이동
- **내비게이션 숨김**: 기존 인라인 네비게이션 숨기기

- 메뉴 스타일: 슬라이드 방식 또는 모달 형태
