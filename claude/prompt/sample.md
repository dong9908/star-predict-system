퍼블리싱된 웹리소스를 리액트 프로젝트로 변환하는 작업을 진행할꺼야.

sample 폴더는 퍼블리싱 작업된 html,css,js 파일이 들어있는 디렉토리야.
index.html만 작업된 상태이고, 전체소스 분석해서 아래 요구사항에 맞게 작업할 수 있도록 작업계획 작성해줘
작업계획은 prompt 폴더 안에 .md 파일로 저장해줘

- 프로젝트 경로 : C:\dev\front
- 원본 위치 : sample/
- 프레임워크 : react (vite)
- 언어 : javascript
- 라우터 경로 : /
- 컴포넌트 위치 : src/components
- 페이지 위치 : src/pages
- 헤더, 푸터 공통 컴포넌트로 분리
- css : 스타일 컴포넌트 
- 작업계획서 파일명 : 작업계획.md
