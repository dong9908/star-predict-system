# Star Predict System - 새 페이지 추가 작업 프롬프트

## 📋 작업 개요
기존 ASTRA 프로젝트의 Header 메뉴에 4개의 새로운 페이지를 추가합니다. 각 페이지는 별자리 관련 기능을 제공합니다.

## 🎯 페이지별 상세 요구사항

### 1️⃣ 별자리 찾기 (ConstellationFindPage.jsx)
**경로:** `/constellation-find`

**기능:**
- 사진 업로드 기능 (드래그 & 드롭, 클릭 업로드)
- 지원 파일: JPG, PNG (최대 10MB)
- 3단계 프로세스 표시:
  - Step 01: 사진 업로드 모드
  - Step 02: 별자리 분석
  - Step 03: 결과 확인
- 업로드 후 별자리 인식 결과 표시
- 추가 기능 카드:
  - 어둠은 장소에서 촬영
  - 카메라를 흔들지 않기
  - 별이 선명한 사진

**디자인:**
- Header 메뉴: "별자리 찾기"로 링크 설정
- 배경: 별 배경 (기존 테마 유지)
- 칼라: 보라색 (#a78bfa) 액센트

---

### 2️⃣ 별자리 위치 찾기 (ConstellationLocationPage.jsx)
**경로:** `/constellation-location`

**기능:**
- 별자리 선택 검색 입력 필드
- 현재 시각 설정 (날짜 & 시간)
- 사용자 위치 설정 (위도/경도)
- 별자리 3D/2D 시각화 (별들이 연결된 형태 표시)
- 현재 위치에서 관측 가능한 별자리 표시
- 계절/시간에 따른 별자리 위치 변동 표시

**상세 기능:**
- Input 01: 첫 글자 별자리를 입력해주세요 (예: 오리온자리)
- Input 02: 관측할 날짜와 시간을 입력해주세요 (YYYY-MM-DD, HH:MM)
- Input 03: 위치 설정 버튼을 눌러 위치를 지정해주세요
- 현재 위치 설정 완료 체크 표시

**디자인:**
- 왼쪽: 입력 폼
- 오른쪽: 별자리 시각화 캔버스
- 별자리 연결선: 보라색 또는 청색

---

### 3️⃣ 별자리 도감 (ConstellationCatalogPage.jsx)
**경로:** `/constellation-catalog`

**기능:**
- 88개 별자리 도감 표시
- 발견한 별자리와 미발견 별자리 구분
- 필터 기능: "전체 88", "발견 6", "미발견 82"
- 별자리 검색 기능
- 발견 진행도 표시 (원형 프로그레스 바)

**데이터 표시:**
- 좌측: 도감 정보
  - "나의 도감"
  - "전체 88개 중 6개 발견"
  - 진행도 (%) 표시
  - 최근 발견/이전 달 정보
- 우측: 별자리 그리드
  - 각 별자리 카드에 별 그림 표시
  - 별자리 이름, 발견 날짜 표시
  - NEW 배지 (최신 발견)
  - 미발견 별자리는 빈 카드 (아이콘만 표시)

**디자인:**
- 그리드: 4~5개 컬럼
- 카드 호버 효과
- 별자리 이미지/아이콘 필요

---

### 4️⃣ 오늘의 운세 (FortuneReadingPage.jsx)
**경로:** `/fortune-reading`

**기능:**
- 사용자 별자리 정보 표시 (별자리 이름, 생년월일)
- 오늘의 종합 운세 텍스트 표시
- 운세 상세 정보 (유료 기능)
- 결제 기능

**데이터:**
- 사용자 별자리: localStorage에서 조회
- 오늘 날짜 자동 표시
- 운세 텍스트: 백엔드 API에서 조회 (필요시)

**구성:**
- 상단: 사용자 별자리 정보 박스
  - 별자리 아이콘
  - 별자리 이름
  - 생년월일, 성별
  - "별자리 기본 문석" 버튼
- 중앙: 오늘의 종합 운세
  - 제목: "오늘의 종합 운세"
  - 날짜: "2026년 8월 25일 화요일"
  - 상세 텍스트 (여러 문단)
- 하단: 운세 상세 정보 (결제 필요)
  - 아이콘, 제목, 가격 표시
  - 결제 버튼
  - 가격: ₩1,900

**디자인:**
- 배경: 별 배경
- 칼라: 보라색 액센트
- 결제 버튼: 보라색 그래디언트

## 📐 디자인 가이드

**기존 테마 유지:**
- 배경: 어두운 별 테마 (dark navy/black)
- 주 색상: 보라색 (#a78bfa)
- 보조 색상: 청색/사이안
- 폰트: 기존 프로젝트 폰트 사용

**컴포넌트 스타일:**
- Input 필드: 보라색 테두리
- 버튼: 보라색 배경 또는 보라색 테두리 아웃라인
- 카드: 어두운 배경에 보라색/청색 테두리
- 호버 효과: 밝은 보라색 글로우

1. **이미지/아이콘:**
   - 별자리 도감 페이지에는 별자리 별 패턴 이미지 필요
