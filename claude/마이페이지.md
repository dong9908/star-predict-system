# 마이 페이지 구현 프롬프트

## 요구사항

헤더의 "마이 페이지" 메뉴를 클릭했을 때, 다음과 같은 마이 페이지를 구현해야 합니다. 이미 마이 페이지가 존재하면 코드를 수정하는 방향으로 갑니다.

## 페이지 레이아웃 및 구조

### 1. 프로필 섹션 (상단)
- **프로필 아이콘**: 사용자 프로필 아이콘 (원형)
- **사용자명**: 로그인한 사용자의 이름 표시 (예: 홍길동)
- **회원 정보 수정 버튼**: 보라색 버튼으로 회원 정보 수정 페이지로 이동
- **별자리 정보**: "획득한 별자리 X/88" 형식으로 표시
- **배지**: 사용자 등급 또는 업적 배지 표시 (예: "별자리 수집가")
  - 배지는 다양한 색상 테두리로 구분됨 (보라색, 파란색, 초록색, 노란색, 빨간색 등)

### 2. 탭 메뉴
3개의 탭으로 구성:
- **청중** (기본 선택): 보라색 배경
- **배경**: 다크 배경
- **프로필**: 다크 배경

### 3. 콘텐츠 영역 (청중 탭)
**"최극한 징조" 섹션** 제목 표시

사용자의 별자리 특성을 카테고리별로 표시하는 카드 형태:

| 카드 | 내용 |
|------|------|
| 별자리 알은 | 별자리 여정을 시작한 탐험가 (보라색 테두리) |
| 별빛 관측자 | 밤하늘을 구종한 바라본 관측가 (파란색 테두리) |
| 별빛 추적자 | 어린 별자리를 자아낸 탐험가 (초록색 테두리) |
| 별자리 수집가 | 다양한 별자리를 모은 수집가 (노란색 테두리) |
| 우주 탐험가 | 밤하늘 너머의 궁금 욕망 (빨간색 테두리) |

각 카드의 구성:
- 아이콘 (별 모양의 심볼)
- 카테고리 제목
- 설명 텍스트
- 색상별 테두리 (각 카테고리별로 다른 색상)

### 4. 화면 하단
- "최극한 징조를 선택하면 다른 징조로 정정할 수 있습니다." 안내 문구

## 디자인 및 스타일
- **배경**: 다크 네이비 배경 (어두운 우주 테마)
- **색상 팔레트**:
  - 보라색: #9333ea, #a855f7
  - 파란색: #3b82f6
  - 초록색: #10b981
  - 노란색/황금색: #f59e0b
  - 빨간색: #ef4444
  - 다크 네이비: #0f172a, #1e293b
- **카드**: 반투명 검은색 배경에 색상별 테두리
- **폰트**: 깔끔한 한글 폰트 (무게감 있는 디자인)

## 기능 요구사항
1. 로그인하지 않은 사용자는 로그인 페이지로 리다이렉트
2. 로그인한 사용자만 마이 페이지 접근 가능
3. 사용자 정보는 localStorage의 user 객체에서 조회
4. 회원 정보 수정 버튼 클릭 시 회원 정보 수정 페이지로 이동
5. 탭 전환 기능 구현 (현재는 청중 탭만 구현 필요)
6. 반응형 디자인 적용 (모바일/태블릿/데스크톱)
