## 2. 작업 A: 별자리 정보 페이지 (`ConstellationInfoPage`) 레이아웃 및 반응형 개선

### 2.1 좌우 높이 및 하단 끝선 일치화 (데스크톱)

**목표:**  
데스크톱 환경에서 좌측 상세 정보 영역과 우측 검색/목록 영역의 높이를 동일하게 맞추고, 하단 끝선을 완벽하게 일치시킴

**구현 상세:**

#### 단계 1: 부모 컨테이너 스타일 수정
- **파일:** `ConstellationInfoPage.styles.js`
- **대상 컴포넌트:** `PageWrapper` (또는 유사한 부모 컨테이너)
- **변경 사항:**
  ```javascript
  export const PageWrapper = styled.div`
    display: flex;
    height: 100vh;  // 또는 적절한 높이
    align-items: stretch;  // 양쪽 자식 요소를 동일 높이로 확장
  `;
  ```
- **이유:** `align-items: stretch`를 통해 두 자식 요소(`DetailSection`, `ConstellationListContainer`)가 부모의 높이를 전부 차지하도록 강제

#### 단계 2: 우측 목록 영역의 내부 스크롤 설정
- **파일:** `ConstellationInfoPage.styles.js`
- **대상 컴포넌트:** `ConstellationListContainer` (또는 목록을 감싸는 컨테이너)
- **변경 사항:**
  ```javascript
  export const ConstellationListContainer = styled.div`
    flex: 1;
    display: flex;
    flex-direction: column;
    overflow-y: auto;  // 카드 영역만 스크롤
    overflow-x: hidden;
  `;
  ```
- **이유:** 내부 스크롤을 통해 하단 버튼 또는 푸터의 끝선을 항상 유지

#### 단계 3: 카드 영역 스타일 확인 및 수정
- **대상:** 별자리 카드를 감싸는 컨테이너
- **확인 사항:**
  - `flex: 1` 또는 유사 설정으로 우측 영역 내에서 자유롭게 확장되는지 확인
  - `margin-bottom` 또는 `padding-bottom`이 과도하게 설정되어 있지 않은지 확인
  - 카드 내부 높이가 고정값이 아닌 `auto` 또는 백분율로 설정되어 있는지 확인

**검증 항목:**

- [ ] 우측 목록 영역이 스크롤되고 하단 끝선이 유지되는가?
- [ ] 좌측 상세 정보 영역의 하단 요소가 우측 하단과 일치하는가?

### 2.2 모바일 반응형 개선 (1024px 이하)

**목표:**  
모바일 화면에서 우측 검색/목록 영역을 상단에, 좌측 상세 정보 영역을 하단에 배치

**구현 상세:**

#### 단계 1: Flexbox Order 속성 설정
- **파일:** `ConstellationInfoPage.styles.js`
- **추가 CSS:**
  ```javascript
  @media (max-width: 1024px) {
    export const PageWrapper = styled.div`
      flex-direction: column;  // 세로 배치로 변경
      height: auto;
      align-items: stretch;
    `;

    export const ConstellationListContainer = styled.div`
      order: 1;  // 상단에 배치
      max-height: 50vh;  // 또는 적절한 높이
      overflow-y: auto;
    `;

    export const DetailSection = styled.div`
      order: 2;  // 하단에 배치
      min-height: auto;
      overflow-y: auto;
      max-height: 50vh;
    `;
  }
  ```
- **이유:** `order` 속성으로 시각적 순서를 변경하되, HTML 구조는 유지

### 3.3 관측 불가 상태 예외 처리

**목표:**  
고도 및 방향 데이터가 측정 불가능한 경우(지평선 아래 등), 명확하게 '관측 불가 (지평선 아래)' 표시

**구현 상세:**

#### 단계 1: 유틸리티 함수 생성
- **파일:** 신규 생성 또는 기존 유틸리티 파일에 추가
- **함수:**
  ```javascript
  export const formatObservationValue = (value, label) => {
    // value가 null, undefined, 또는 특정 에러 코드인 경우
    if (value === null || value === undefined || value === -999) {
      if (label === 'altitude') {
        return '관측 불가 (지평선 아래)';
      }
      return '-';
    }
    // 숫자인 경우 소수점 2자리까지만 표시
    return typeof value === 'number' ? value.toFixed(2) : value;
  };
  ```

#### 단계 2: JSX에서 활용
- **파일:** `ConstellationLocationPage.jsx`
- **변경 사항:**
  ```javascript
  import { formatObservationValue } from '../utils/observationUtils';

  <ResultRow>
    <ResultLabel>고도 (Altitude)</ResultLabel>
    <ResultValue>
      {formatObservationValue(observationData?.altitude, 'altitude')}
    </ResultValue>
  </ResultRow>
  <ResultRow>
    <ResultLabel>방향 (Azimuth)</ResultLabel>
    <ResultValue>
      {formatObservationValue(observationData?.azimuth, 'azimuth')}
    </ResultValue>
  </ResultRow>
  ```

**검증 항목:**
- [ ] 유효한 값이 올바르게 표시되는가?
- [ ] null/undefined 값이 '관측 불가' 또는 '-'로 표시되는가?
- [ ] 값의 형식(소수점, 단위 등)이 일관되는가?
