# 작업 계획서 (수정2)

## 1. 개요
- **목표**: 프론트엔드(`front/`) 폴더 내의 컴포넌트 및 스타일 코드를 수정하여 레이아웃 정렬 오류를 바로잡고, 별자리 위치 및 정보 페이지의 UI 요구사항을 완벽히 반영하는 작업계획 만들어 claude 폴더에 수정2.md 파일로 저장

---

## 2. 세부 작업 항목

### A. 별자리 정보 페이지 (`ConstellationInfoPage`) 레이아웃 및 반응형 개선
- **좌우 높이 및 하단 끝선 일치화**: 
  - 데스크톱 환경에서 좌측 상세 정보 영역(`DetailSection`)과 우측 검색/목록 영역(`ConstellationListContainer`)이 동일한 높이를 공유하도록 부모 컨테이너(`PageWrapper`)에 `align-items: stretch` 적용
  - 우측 목록 영역 내부가 길어질 경우, 카드 영역만 내부 스크롤(`overflow-y: auto`)이 작동하도록 설정하여 양쪽 레이아웃의 하단 끝선을 완벽하게 일치시킴
- **모바일 화면 요소 순서 변경 (Order 변경)**:
  - 반응형 미디어 쿼리(`@media (max-width: 1024px)`) 환경에서 우측의 검색 및 목록 영역이 상단(`order: 1`)으로 배치되도록 수정하고, 하단에 별자리 정보 영역(`order: 2`)이 오도록 순서 재조정

### B. 별자리 위치 페이지 (`ConstellationLocationPage`) 기능 및 UI 추가
- **하단 운세 버튼 추가**: 
  - 04번 관측 결과 영역 하단에 `'오늘의 나의 운세 보기 (pro)'` 버튼을 추가하고, 클릭 시 `/fortune-reading` 경로로 이동하도록 구현 (`BottomButtonWrapper` 스타일 적용)
- **관측 결과 시각화 레이아웃 개선**:
  - `front-img/관측 정보.png` 레퍼런스 디자인과 동일하게 관측 상세 정보 영역을 행(Row) 단위 구조로 개편 (`ResultContainer`, `ResultRow`, `ResultLabel`, `ResultValue` 컴포넌트 분리 적용)
  - 관측 결과의 고도 및 방향 데이터 중 측정 불가(지평선 아래 등) 상태일 경우, 명확하게 `'관측 불가 (지평선 아래)'` 및 `'-'` 문구가 표시되도록 예외 처리 구현
- **별자리 정보 연동 버튼 추가**:
  - 04번 칸의 관측 상세 정보 박스 내부에 `'별자리 정보 보러가기'` 버튼을 배치하여, 클릭 시 선택된 별자리의 ID 값을 담아 상세 정보 페이지(`/constellation-info?constellation_id=...`)로 즉시 이동할 수 있도록 연동
